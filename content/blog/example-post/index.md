Start with the idea you want to explain. Articles do not need an image: the title,
introduction, and text provide the layout.

## Give the idea some context

Write your article in Markdown. You can use **emphasis**, lists, links, and inline
`code`.

- Explain the problem.
- Show an example.
- Describe what the reader can try next.

## Show an example

```text
$ toit run hello.toit
Hello, world!
```

> A quotation or a short aside can help break up a longer explanation.

End with a useful next step, such as a link to the
[language guide](https://docs.toit.io/language/).
